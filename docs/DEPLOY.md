# 젤리 던전 배포 안내 (구글 Apps Script)

> 개발을 잘 몰라도 따라 할 수 있게 쓴 안내서예요. **구글 계정 하나**와 **30분**이면 충분해요.
> 이 문서를 끝까지 따라 하면, 주소(링크) 하나로 누구나 휴대폰·태블릿·컴퓨터에서 게임을 할 수 있고,
> 게임이 끝난 뒤 점수가 **내가 가진 구글 스프레드시트**에 쌓여서 **랭킹**으로 보여요.

---

## 0. 먼저 알아 두기

| 말 | 쉬운 뜻 |
|----|---------|
| **Apps Script** | 구글이 공짜로 빌려주는 작은 서버예요. 게임 화면을 보여주고, 점수를 시트에 적어 줘요. |
| **웹 앱** | Apps Script 로 만든 "누구나 열 수 있는 웹페이지"예요. 주소가 하나 생겨요. |
| **배포** | 내가 쓴 코드를 "이 주소로 공개할게요" 하고 올리는 일이에요. |
| **스크립트 속성** | 코드 밖에 적어 두는 설정값이에요. (이 프로젝트는 `SHEET_ID` 하나만 써요. 안 적어도 돼요!) |
| **`/exec` 주소** | 배포한 버전으로 열리는 **진짜 주소**예요. 아이들에게 나눠 줄 주소는 이거예요. |
| **`/dev` 주소** | 내가 방금 고친 **최신 코드**를 나만 시험해 보는 주소예요. 남에게 주면 안 열려요. |

**게임 파일은 `src` 폴더 안에 있어요.** Apps Script 에 올릴 것은 딱 이 11개예요.

| 올릴 파일 | 종류 |
|-----------|------|
| `Code.gs` | 서버 코드 (점수 저장·랭킹) |
| `appsscript.json` | 프로젝트 설정 (웹 앱으로 쓰겠다는 설정) |
| `index.html` | 게임 틀 (아래 8개 파일을 끼워 넣어요) |
| `style.html`, `js_core.html`, `js_player.html`, `js_enemies.html`, `js_stage.html`, `js_ui.html`, `js_server.html`, `js_main.html` | 게임 화면·그림·규칙 |

> `docs`, `tools`, `prototype`, `GUIDE.md` 는 **올리지 않아요.** (만드는 사람용 자료예요.)

### 서버 없이 먼저 해 보고 싶다면
컴퓨터에서 `node tools/build-local.mjs` 를 실행하면 `dist/index.html` 이 만들어져요. 더블클릭하면 바로 게임이 열려요.
이때는 서버가 없어서 점수가 **그 기기 안에만** 저장돼요. ("내 기기에만 저장됐어요" 라고 보여요.)

## 1. 방법 A — 브라우저로만 하기 (설치 없음)

### A-1. (추천) 랭킹이 쌓일 구글 스프레드시트 먼저 만들기
1. <https://sheets.google.com> 에서 **빈 스프레드시트**를 만들어요. 이름은 `젤리 던전 랭킹` 처럼 알아보기 쉽게 해요.
2. 위쪽 메뉴에서 **확장 프로그램 → Apps Script** 를 눌러요. 새 탭에 편집기가 열려요.
   이렇게 열면 이 프로젝트가 시트에 **붙어 있어서(컨테이너 바인딩)** 아무 설정 없이 그 시트에 점수가 쌓여요.

> 시트를 먼저 만들기 싫다면 <https://script.google.com> → **새 프로젝트** 로 시작해도 돼요.
> 그러면 처음 저장할 때 `젤리 던전 랭킹` 시트가 내 구글 드라이브에 **자동으로** 만들어져요.
> (만든 시트 번호는 스크립트 속성 `SHEET_ID` 에 자동으로 기억돼요.)

### A-2. 파일 만들기
편집기 왼쪽의 **파일** 옆 **+** 버튼으로 파일을 만들고, `src` 폴더의 같은 이름 파일 내용을 **통째로 복사해서 붙여 넣어요.**

1. `Code.gs` 는 이미 있어요. 안의 내용을 지우고 `src/Code.gs` 내용으로 바꿔요.
2. **+ → HTML** 을 눌러 아래 9개를 하나씩 만들어요. **이름에 `.html` 을 붙이지 않아요!** (자동으로 붙어요)
   `index`, `style`, `js_core`, `js_player`, `js_enemies`, `js_stage`, `js_ui`, `js_server`, `js_main`
3. 이름 철자가 하나라도 다르면 "하얀 화면"이 돼요. 꼭 위 이름 그대로 써요. (대소문자·밑줄 포함)

> **더 쉬운 길:** 컴퓨터에서 `node tools/build-local.mjs` 를 실행하면 `dist/index.html` 에 게임이 **한 파일로 합쳐져** 나와요.
> 이 파일 내용을 `index` 하나에만 붙여 넣으면 나머지 8개 HTML 파일은 필요 없어요. (`Code.gs` 와 `appsscript.json` 은 그대로 필요해요.)
> 단, 게임을 고칠 때마다 다시 합쳐서 붙여 넣어야 해요. 자주 고친다면 방법 B(clasp)가 편해요.

### A-3. 프로젝트 설정(appsscript.json) 맞추기
1. 왼쪽 **프로젝트 설정(톱니바퀴)** 을 눌러요.
2. **"편집기에서 'appsscript.json' 매니페스트 파일 표시"** 에 체크해요.
3. 편집기로 돌아가 `appsscript.json` 을 열고 내용을 `src/appsscript.json` 으로 바꿔요.

```json
{
  "timeZone": "Asia/Seoul",
  "dependencies": {},
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8",
  "webapp": {
    "executeAs": "USER_DEPLOYING",
    "access": "ANYONE_ANONYMOUS"
  }
}
```

뜻: 한국 시간 사용 / 최신 자바스크립트(V8) / **"나(배포한 사람)의 권한으로 실행"** / **"로그인 없이 누구나 접속"**.
(이 두 설정 덕분에 아이들이 구글 로그인이나 권한 허용을 할 필요가 없어요.)

### A-4. 한 번 실행해서 권한 허용하기 (처음 한 번만)
1. 편집기 위쪽의 함수 선택 칸에서 **`setup`** 을 골라요.
2. **실행** 을 눌러요. **권한 검토** 창이 뜨면 아래 순서로 진행해요.
   1. 내 구글 계정을 골라요.
   2. **"Google에서 확인하지 않은 앱입니다"** 가 나오면 정상이에요. 내가 만든 앱이라 그래요. **고급** 을 눌러요.
   3. **"젤리 던전(안전하지 않음)으로 이동"** 을 눌러요.
   4. 요청하는 권한(스프레드시트 보기/수정)을 **허용** 해요.
3. 아래 **실행 로그** 에 `준비 끝! 랭킹이 저장되는 시트: https://docs.google.com/...` 이 나오면 성공이에요.
   그 시트를 열어 보면 `Scores` 탭에 머리글(`시간 | 닉네임 | 점수 | 별 | 난이도 | 스테이지 | 시간(초)`)이 있어요.

> 허용하는 권한은 "내 스프레드시트를 읽고 쓰기" 예요. 점수를 시트에 적어야 해서 필요해요.
> 이메일이나 연락처 같은 다른 것은 읽지 않아요.

### A-5. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포** 를 눌러요.
2. **유형 선택(톱니바퀴) → 웹 앱** 을 골라요.
3. 아래처럼 채워요.
   - **설명:** `젤리 던전 1.0`
   - **다음 사용자로 실행:** **나**
   - **액세스 권한이 있는 사용자:** **모든 사용자**
4. **배포** 를 눌러요. 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)가 나와요. **복사해 둬요!**
5. 새 탭에 붙여 넣어 열어 봐요. 게임 제목 화면이 나오면 성공이에요. 닉네임을 적고 한 판 해 봐요.
6. 게임이 끝나면 `✅ 저장됐어요!` 가 나오고, 시트의 `Scores` 탭에 한 줄이 생겨요.

## 2. 방법 B — clasp 로 한 번에 올리기 (컴퓨터에 익숙한 어른용)

`clasp` 는 구글이 만든 "내 컴퓨터의 폴더 → Apps Script 프로젝트" 업로드 도구예요. `src` 폴더를 통째로 올려 줘서, 고칠 때마다 한 줄이면 돼요.

```bash
# 1) 한 번만 설치·로그인 (Node.js 가 필요해요)
npm install -g @google/clasp
clasp login                       # 브라우저가 열리면 구글 계정으로 로그인
# 처음이라면 https://script.google.com/home/usersettings 에서 "Google Apps Script API" 를 켜요

# 2) 프로젝트 폴더에서 새 Apps Script 프로젝트 만들기 (src 폴더가 프로젝트의 루트)
cd seongmo-fight
clasp create --type webapp --title "젤리 던전" --rootDir src
#   → 프로젝트 루트에 .clasp.json 이 생겨요 (안에 scriptId 가 있어요)
#   → 만약 src/appsscript.json 이 덮어써졌다면 `git checkout src/appsscript.json` 으로 되돌려요
#   (이미 만들어 둔 프로젝트에 연결하려면:  clasp clone <스크립트ID> --rootDir src )

# 3) 올리기
clasp push                        # src 폴더의 파일이 전부 올라가요 (docs, tools 는 안 올라가요)

# 4) 한 번 실행해서 권한 허용 + 시트 준비 (편집기에서 하는 것이 가장 쉬워요)
clasp open                        # 편집기가 열려요 → 함수 `setup` 선택 → 실행 → 권한 허용 (위 A-4)

# 5) 웹 앱으로 배포
clasp deploy --description "젤리 던전 1.0"
clasp deployments                 # 배포 목록과 배포 ID 확인
```

- 웹 앱 주소는 `https://script.google.com/macros/s/<배포 ID>/exec` 예요.
- 시트에 묶인 프로젝트로 쓰고 싶다면 방법 A-1 처럼 시트에서 **확장 프로그램 → Apps Script** 로 프로젝트를 만든 뒤, 그 프로젝트의 스크립트 ID 로 `clasp clone <스크립트ID> --rootDir src` 를 해요.
- `clasp` 의 명령 이름은 버전에 따라 조금씩 달라질 수 있어요. 막히면 `clasp --help` 와 공식 문서(<https://github.com/google/clasp>)를 봐요.
- `.clasp.json` 에는 내 프로젝트 ID 가 들어 있어요. 비밀번호는 아니지만 공개 저장소에 올릴 필요는 없어요.

## 3. 스크립트 속성 (안 해도 돼요!)

기본은 아무 설정 없이 동작해요. 랭킹 시트를 **내가 정한 파일로** 쓰고 싶을 때만 해요.

1. 편집기 왼쪽 **프로젝트 설정(톱니바퀴)** → 아래쪽 **스크립트 속성** → **스크립트 속성 추가**
2. 속성 `SHEET_ID`, 값은 시트 주소 속 긴 글자예요.
   `https://docs.google.com/spreadsheets/d/`**`여기_긴_글자`**`/edit`
3. 저장해요. 그 파일 안에 `Scores` 탭이 없으면 자동으로 만들어 줘요.

시트를 고르는 순서는 이래요.

1. 스크립트 속성 `SHEET_ID` 가 있으면 그 시트
2. 없으면 프로젝트가 붙어 있는 시트 (방법 A-1)
3. 그것도 없으면 `젤리 던전 랭킹` 시트를 새로 만들고, 그 번호를 `SHEET_ID` 에 **자동으로 적어 둬요**

> `SHEET_ID` 가 적혀 있는데 시트를 열 수 없으면(지웠거나 번호가 틀림) **새 시트를 몰래 만들지 않고** 오류로 알려요.
> 그래야 예전 기록이 사라진 줄 모르고 지나가는 일이 없어요. 번호를 고치거나 속성을 지우면 돼요.

## 4. 코드를 고친 뒤 다시 배포하기 (제일 헷갈리는 부분!)

**편집기에서 코드를 저장하는 것만으로는 `/exec` 주소의 게임이 바뀌지 않아요.** 새 버전을 만들어 **같은 배포에 덮어써야** 해요.

1. **배포 → 배포 관리**
2. 고치려는 배포 옆 **연필(수정)** 아이콘
3. **버전:** → **새 버전** 선택, 설명을 적어요 (예: `1.1 보스 쉬워짐`)
4. **배포**

그러면 **주소는 그대로**이고 안의 게임만 새 버전이 돼요. 아이들에게 새 링크를 줄 필요가 없어요.

> ⚠ **배포 → 새 배포** 를 또 누르면 **완전히 새 주소**가 생겨요. 예전 주소는 옛 버전으로 그대로 남아요.
> (옛 주소로 들어온 사람은 옛 게임을 보게 돼요.) 일부러 그러는 게 아니라면 "배포 관리 → 수정" 을 써요.

| 주소 | 어떤 코드가 실행되나요 | 누가 열 수 있나요 | 언제 쓰나요 |
|------|----------------------|------------------|-------------|
| `…/exec` | **배포한 버전** (새 버전을 만들어야 바뀜) | 모든 사람 | 아이들에게 나눠 줄 진짜 주소 |
| `…/dev` | **저장한 최신 코드** (바로 바뀜) | 편집 권한이 있는 나 | 고친 것을 바로 시험할 때 (**배포 → 배포 테스트**) |

clasp 를 쓴다면: `clasp push` 로 올린 뒤 `clasp deployments` 로 배포 ID 를 확인하고
`clasp deploy --deploymentId <배포 ID> --description "1.1"` 로 **같은 배포를 갱신**해요. (`--deploymentId` 를 안 쓰면 새 배포가 생겨요.)

## 5. QR 코드로 나눠 주기

아이들이 긴 주소를 치지 않게 QR 코드를 만들어 줘요.

- **컴퓨터 크롬:** `/exec` 주소로 들어간 뒤 주소창 오른쪽 **공유 아이콘 → QR 코드 만들기** → **다운로드** 해서 인쇄하거나 화면에 띄워요.
- **안드로이드 크롬:** 점 3개 메뉴 → **공유 → QR 코드**
- 나눠 주기 전에 **다른 기기(내 휴대폰)로 QR 을 찍어서** 게임이 열리는지, 점수가 저장되는지 꼭 확인해요.
- 아이들이 쓰는 기기는 **화면을 가로로** 돌리고, 처음 한 번 **「시작!」** 버튼을 눌러야 소리가 나요. (브라우저 규칙이에요)

## 6. 학교·회사(구글 워크스페이스) 계정으로 배포할 때 주의

| 상황 | 설명 |
|------|------|
| 액세스 권한에 **"모든 사용자"** 가 안 보여요 | 관리자가 "조직 밖 공유/로그인 없는 접속"을 막아 둔 거예요. 관리자에게 허용을 요청하거나, 개인 구글 계정으로 배포해요. |
| 학생들이 학교 계정으로만 열게 하고 싶어요 | `appsscript.json` 의 `"access": "ANYONE_ANONYMOUS"` 를 `"DOMAIN"` 으로 바꾸고 새 버전으로 배포해요. 그러면 같은 조직 로그인이 필요해요. |
| 학교 계정으로 만든 시트 | 시트는 **만든 사람(배포한 사람)의 드라이브**에 생겨요. 선생님 계정이 바뀌거나 삭제되면 기록도 함께 사라질 수 있어요. 오래 쓸 거라면 공용(공유 드라이브) 시트에 `SHEET_ID` 를 연결해요. |
| 개인정보 규정 | 학교·기관에서 쓰기 전에 **개인정보 담당자에게 알리고** 학교 규정을 확인해요. (아래 "개인정보" 참고) |

## 7. 사용량 한도 (쿼터)

Apps Script 는 공짜인 대신 **사용 한도**가 있어요. 정확한 숫자는 구글이 가끔 바꾸니 꼭 공식 문서에서 확인해요.
공식 문서: <https://developers.google.com/apps-script/guides/services/quotas>

- **동시에 실행되는 개수**(simultaneous executions)에 한도가 있어요. 이 글을 쓸 때 문서에는 "사용자당 30개" 라고 되어 있었어요.
  이 게임은 **게임 화면은 한 번 불러오고, 점수 저장·랭킹 조회 때만** 서버를 쓰기 때문에 한 반(수십 명) 정도는 보통 괜찮아요.
- 점수를 저장할 때는 **한 번에 한 명씩** 줄을 서서 시트에 써요. (겹쳐 쓰다가 줄이 섞이는 것을 막으려고요)
  한 반 전원이 **같은 순간에** 저장을 누르면 뒷사람은 몇 초 기다려야 해요. 그동안 못 쓰면 `📱 내 기기에만 저장됐어요` 가 나올 수 있어요. → 다시 시도하거나, "다 같이 동시에 누르지 말고 한 줄씩" 안내해 줘요.
- 랭킹은 **30초 동안 기억**해 두었다가 보여줘요. 그래서 조회가 많아도 시트를 매번 읽지 않아요. (점수가 저장되면 기억을 바로 지워요.)
- 구글 서비스 점검·일시 오류가 있을 수 있어요. 그때도 게임은 멈추지 않고, 점수는 **그 기기에 먼저 저장**돼요.
- 시트는 저장할 때마다 **한 줄씩 늘어나요.** 몇 천 줄이 넘어 느려지면 오래된 줄을 지워 줘요. (랭킹은 닉네임별 최고 점수만 보여줘요.)

## 8. 문제 해결

| 증상 | 이유 | 해결 |
|------|------|------|
| **하얀 화면**이 나와요 | `index` 안에서 끼워 넣을 HTML 파일 이름이 틀렸거나 빠졌어요 / 파일 내용이 일부만 붙었어요 | 파일 이름(`js_core`, `js_ui` …)을 위 표와 **글자 하나까지** 비교해요. 브라우저에서 `F12` → **Console** 에 빨간 글자가 있는지 봐요. `…/dev` 주소로 열면 오류가 더 잘 보여요. |
| `스크립트 함수를 찾을 수 없습니다: doGet` | `Code.gs` 가 없거나 비어 있거나, 저장 안 한 채 배포했어요 | `Code.gs` 에 `src/Code.gs` 내용이 있는지, 저장(Ctrl+S)했는지 확인하고 **새 버전으로** 다시 배포해요. |
| `죄송합니다. 지금은 파일을 열 수 없습니다` / 구글 로그인 화면 | 주소를 잘못 복사했거나, 접근 권한이 "모든 사용자" 가 아니에요 / 구글 계정을 여러 개 로그인해 둔 상태 | 배포 관리에서 **액세스 권한 = 모든 사용자** 인지 확인해요. 시크릿 창에서 열어 봐요. 주소 끝이 `/exec` 인지 확인해요. |
| 권한 허용 화면이 나와요 / "Google에서 확인하지 않은 앱" | **정상**이에요. 내가 만든 앱을 내가 처음 허용하는 거예요. | **고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용**. 아이들 화면에는 이 창이 나오지 않아요. |
| 고쳤는데 **게임이 그대로**예요 | 새 버전을 안 만들었어요 / 브라우저가 옛것을 기억해요 | "4. 다시 배포하기"의 **배포 관리 → 수정 → 새 버전**. 그다음 `Ctrl+Shift+R`(강력 새로고침)이나 시크릿 창으로 열어요. |
| **랭킹이 비어** 있어요 | 아직 저장된 기록이 없어요 / 서버가 안 돼서 지금 **그 기기의 기록**만 보고 있어요 / 방금 저장했는데 30초 기억에 걸렸어요 | 한 판 하고 `✅ 저장됐어요!` 가 나오는지 봐요. 시트 `Scores` 탭에 줄이 쌓이는지 봐요. (저장하면 랭킹 기억은 바로 새로 고쳐져요.) |
| `📱 내 기기에만 저장됐어요` | 서버 저장에 실패했어요 (인터넷 끊김, 서버가 바쁨, 배포가 옛 버전 등). 점수는 그 기기에 남아 있어요 | 잠시 뒤 **다시 시도**. 계속이면 편집기 왼쪽 **실행 내역**에서 실패한 실행의 오류 문구를 확인해요. |
| 시트에 줄이 **안 쌓여요** | 게임이 보는 시트와 내가 보는 시트가 달라요 | 편집기 → `setup` 실행 → **실행 로그**의 시트 주소를 열어 봐요. 스크립트 속성 `SHEET_ID` 가 다른 시트를 가리키고 있지 않은지 봐요. |
| 로그에 `랭킹 시트를 열 수 없어요` | `SHEET_ID` 가 틀렸거나 시트를 지웠어요 | 스크립트 속성에서 `SHEET_ID` 를 올바른 값으로 고치거나 지우면 새로 만들어요. (지우기 전에 예전 시트가 정말 필요 없는지 확인!) |
| `이 이름은 쓸 수 없어요` | 닉네임이 금칙어 목록에 걸렸어요 | 다른 이름을 쓰게 해요. 너무 자주 잘못 걸리면 아래 "금칙어 고치기"를 봐요. |
| `Service invoked too many times` 같은 영어 오류 | 짧은 시간에 너무 많은 요청이 몰렸어요 (쿼터) | 몇 분 기다린 뒤 다시 해요. 한 반이 한꺼번에 하지 않게 나눠요. |
| 닉네임이 `abc` 로 바뀌었어요 (`=abc` 를 썼는데) | 일부러 그래요. 시트에서 수식으로 읽히는 `= + - @` 로 시작하는 글자는 지워요 | 정상이에요. |

**문제를 찾는 가장 좋은 곳:** 편집기 왼쪽 **실행 내역**(Executions)과 브라우저 `F12` → **Console**.

## 9. 운영 팁

### 랭킹 관리
- **이상한 닉네임 지우기:** 시트 `Scores` 탭에서 그 줄을 지워요. (최대 30초 뒤 랭킹에서도 사라져요.)
- **랭킹 초기화:** 머리글(1행)만 남기고 아래 줄을 전부 지워요. 머리글을 지웠다면 `시간 | 닉네임 | 점수 | 별 | 난이도 | 스테이지 | 시간(초)` 순서로 다시 써 줘요.
- **시트는 가끔 훑어봐요.** 금칙어 목록은 완벽하지 않아서, 어른이 이상한 이름이 없는지 가끔 봐 주면 좋아요.
- 점수는 **기기가 보내 주는 값**이라, 마음먹고 속이면 고칠 수 있어요. (서버가 범위·모양은 검사하지만 "진짜 그렇게 쳤는지"는 알 수 없어요.) 아이들끼리 즐기는 용도로는 충분해요.

### 금칙어 고치기
금칙어 목록은 **두 곳에 똑같이** 있어야 해요. (화면에서 먼저 알려 주고, 서버가 한 번 더 막아요.)
- `src/js_server.html` 안의 `NICKNAME_BLOCKLIST`
- `src/Code.gs` 안의 `BLOCKLIST_`

`// ==== BLOCKLIST START ====` 와 `END` 표시 사이의 배열에 단어를 한 줄 추가해요. (영어는 소문자·띄어쓰기 없이)
`node tools/tests/code-gs.test.mjs` 를 실행하면 두 목록이 같은지 검사해 줘요.

### 점수 규칙 (서버가 다시 검사해요)
닉네임 2~8자(한글·영어·숫자·공백) / 점수 0~999999 정수 / 별 0~3 / 난이도 `easy·normal·hard` / 시간 0~86400초.
같은 닉네임이 **10초 안에 같은 점수**를 또 보내면(더블클릭·재시도) 한 번만 저장해요.
랭킹은 **닉네임별 최고 점수**(영어 대소문자는 같은 이름으로 봐요)를 높은 순으로, 같으면 **먼저 달성한 쪽이 위**예요.

### 시트의 열
`시간 | 닉네임 | 점수 | 별 | 난이도 | 스테이지 | 시간(초)` — 이름과 점수 같은 **게임 숫자만** 있어요.

## 10. 아이들 개인정보 안내 (꼭 읽어 주세요)

**이 게임이 저장하는 것:** 닉네임, 점수, 별 개수, 난이도, 스테이지 이름, 플레이 시간(초), 저장한 시각. **그게 전부예요.**

**이 게임이 저장하지 않는 것:** 이름·이메일·전화번호·학교·나이·사진·위치. 접속한 사람의 구글 계정이나 IP 주소도 코드가 읽지 않고 저장하지 않아요.
(그런 정보를 읽는 기능을 코드에서 일부러 쓰지 않았고, 테스트가 이를 확인해요. 다만 구글이 서비스 운영을 위해 **자체적으로** 쌓는 기록은 구글의 정책을 따라요.)

**왜 이렇게 만들었나요?**
- 우리나라 **개인정보 보호법**은 **만 14세 미만 아동**의 개인정보를 처리하려면 **법정대리인(보호자)의 동의**를 받도록 해요.
  이 게임은 처음부터 **개인정보를 받지 않아서** 동의 절차가 필요 없도록 만들었어요.
  (법 조항과 내용은 바뀔 수 있어요. 학교·기관에서 쓰기 전에는 최신 내용을 [국가법령정보센터](https://www.law.go.kr)나 개인정보 담당자에게 확인해 주세요. 이 문서는 법률 자문이 아니에요.)

**어른이 꼭 해 주세요:**
1. 아이들에게 **"진짜 이름 말고 별명(닉네임)을 써요"** 라고 알려 줘요. 실명, 학교, 전화번호가 닉네임이 되면 그때부터는 개인정보가 될 수 있어요. (닉네임 검사기는 이런 것까지 알아채지 못해요.)
2. 닉네임은 **랭킹에 모두에게 보여요.** 보여도 괜찮은 이름만 쓰게 해요.
3. 스프레드시트를 **다른 사람과 공유하지 않아요.** (공유하면 닉네임 목록이 보여요.) 시트는 만든 사람 계정에만 보여요.
4. 시트의 **기록을 지울 수 있다**는 것(보호자가 삭제를 원하면 해당 닉네임 줄을 지우면 돼요)을 알아 둬요.
5. 서비스 안내 글(QR 옆)에 "닉네임과 점수만 저장돼요" 라고 한 줄 적어 두면 좋아요.
6. 아이들이 오래 하지 않게 해요. 게임은 30분마다 "잠깐 쉬어요!" 알림을 보여줘요.

## 11. 한 장 요약

1. 시트 만들기 → **확장 프로그램 → Apps Script**
2. `Code.gs` + `appsscript.json` + HTML 9개 붙여 넣기 (또는 `clasp push`)
3. 함수 `setup` **실행** → 권한 **허용**
4. **배포 → 새 배포 → 웹 앱** (나로 실행 / 모든 사용자) → `/exec` 주소 복사
5. QR 코드로 나눠 주기 → 한 판 해 보고 시트에 줄이 쌓이는지 확인
6. 고친 뒤에는 **배포 관리 → 수정 → 새 버전 → 배포** (주소는 그대로!)
